### New Consumables
*Able to be equipped like Potions, Hi-Potions, Etc.*

  - Grants Haste to the user for 30 Seconds.
- Chocobo Wing
  - Grants Haste to the user and nearby party members for 30 seconds.
- Light Curtain
  - Grants Protect to the user for 30 seconds.
- Lunar Curtain
  - Grants Shell to the user for 30 seconds.

  - Grants Regen to the user for 30 seconds.

### New Spells
- Protect/Protectra/Protectga
  - Cost: 50 MP
  - Grants Protect Status Effect for (10/20/30 + 10% MAG) Seconds.
- Shell/Shellra/Shellga
  - Cost: 50 MP
  - Grants Shell Status Effect for (10/20/30 + 10% MAG) Seconds.

- Protect

## Birth By Sleep's Finish Commands
I figured it was time to spice up the Finish RC. And what better way to do so than new Finish Commands?

This new menu/system is accessible by going to **[Items]** -> **[Finish Commands]**. 

The progression is basically the same as BBS. And so far only the Level 1 and 2 Finish Commands are functional. Experiment and see what fits you!
